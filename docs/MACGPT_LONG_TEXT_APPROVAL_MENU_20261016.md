# MacGPT: 승인 요청 메뉴 / 대량 텍스트 학습 / 회원 선택창 수정

- `승인 요청` 메뉴는 관리자에게 승인 대기 작업이 있을 때만 표시됩니다. 지식 승인 건은 `/proposals`, 회원 승인 건은 최종관리자의 `/members` 링크로 분리됩니다. 승인·거절 이력은 지식 관리의 `승인·거절 이력` 버튼 또는 `/proposals`에서 언제든 확인할 수 있습니다.
- 회원 권한 `<select>`는 기본 화살표를 숨기고 lucide ChevronDown에 오른쪽 여백을 예약했습니다.
- 채팅 입력창 아래 2시간 제한 문구를 제거했습니다. 서버의 실제 첨부 만료 정책은 그대로 적용됩니다.
- 관리자 텍스트 학습 API는 80,000자까지 허용하고 4,000자 초과 텍스트를 문서 구간으로 나누어 OpenAI에 보냅니다. 글자 수 초과 및 문서 분량 초과는 설명과 함께 거절합니다.
- 병원 지식 변경안은 **기존과 동일하게 관리자 검토 및 승인 이후** 공식 지식이 됩니다. 대량 학습은 주제별 누락·중복이 있을 수 있어 원본 대조가 필요합니다.
- 데이터베이스 SQL 마이그레이션은 없습니다.

### 검증

`npm test && npm run typecheck && npm run lint && npm run build`를 Mac에서 실행하도록 포함했습니다. 본 컨테이너에는 해당 프로젝트의 설치된 npm 의존성이 없어 전체 타입 검사와 빌드는 로컬에서 최종 검증됩니다.
