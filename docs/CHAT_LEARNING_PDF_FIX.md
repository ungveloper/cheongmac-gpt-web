# MacGPT 채팅 UI 및 브랜드북 PDF 학습 수정

- `/api/admin/assist`는 직원 소유·만료시간이 검증된 PDF의 텍스트를 서버에서 추출하여 모델에 전달합니다. 기존 OpenAI `input_file` PDF 거절 HTTP 400 → MacGPT HTTP 422 경로를 우회합니다.
- 텍스트 PDF(최대 PDF 텍스트 85,000자)만 지원하며, 이미지 기반 스캔 PDF·로고 그래픽·시각 규칙은 자동으로 추출되지 않습니다. 시각적인 규칙은 반드시 원본을 보며 검토하세요.
- PDF 분석 결과는 **승인 대기 변경안**이며 모델 재훈련이나 무조건적인 DB 반영을 뜻하지 않습니다. 원내 범위 기본 적용. 의료 주장이나 치료 정보는 게시 전 담당자 검수 필수.
- `pdf-parse@1.1.1` 신규 의존성 추가. `npm install`로 package-lock.json을 갱신합니다.
- DnD 이벤트는 최상위 Workspace에 연결합니다. 파일 드롭 오버레이는 화면 전체를 덮습니다.
- AI 답변 로딩은 점 3개와 동일한 너비의 작은 UI만 차지하며, 각 메시지 아래에 복사 버튼을 제공합니다.
- 개인 정보/환자 기록을 테스트에 넣지 마세요.

## 검증
1. 브랜드북 PDF 첨부 → 학습 모드 ON → 주제별 등록 요청
2. OpenAI 요청에서 PDF 형식 400/422가 재발하지 않는지 확인
3. 학습 변경안 내용을 원본 PDF와 비교하고 담당자가 승인
4. 업로드한 원본 PDF는 대화용 임시 자료이며 Storage 파일 보관함에 자동으로 저장되지 않음
5. ChatGPT와 유사한 사용감을 목표로 하나 완전한 픽셀 단위·기능 동일성은 보장되지 않음
