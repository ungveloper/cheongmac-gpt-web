# MacGPT: 채팅 파일 첨부 (초기 릴리스)

## 역할과 제한

- 직원/관리자 계정 로그인 세션에서만 채팅에 파일 첨부 가능. **공개 홈페이지 API 키로는 사용할 수 없습니다.**
- 허용: PDF, DOCX, XLSX, TXT, MD, PNG, JPG/JPEG. 파일당 10MB, 대화당 3개, 합계 20MB.
- 화면의 📎 버튼으로 파일을 선택한 후 질문 전송. 브라우저 → Supabase Storage **비공개 버킷** 직접 업로드; 서버에는 첨부파일 UUID만 전송.
- 서버는 DB에서 소유자/완료 여부/만료 시각을 매번 확인하고 비공개 Storage에서 다운로드한 바이트를 OpenAI Responses API `input_file`/`input_image`로 전달합니다. 이 데이터는 AI에게 전송되므로 개인정보·환자정보 업로드를 금지합니다.
- 첨부파일은 **공식 지식으로 저장·승인·공개되지 않습니다.** 지식 변경 모드와 동시에 사용하지 않습니다.
- 현재 탭의 대화에서는 파일을 계속 참고하도록 요청별로 재전송합니다(반복 호출 비용 발생). 서버의 만료 시간은 업로드 후 120분. 만료 이후 재업로드 필요.
- 새 대화 또는 첨부 해제 시 서버 삭제를 요청하지만 클라이언트 연결 실패로 잔류할 수 있으므로 자동 정리가 필요합니다.

## DB 및 스토리지 준비

1. Supabase SQL Editor에서 `supabase/migrations/202610150002_chat_attachments.sql`을 **1회 실행**합니다. 최초 마이그레이션을 반복 실행하지 마세요.
2. 기존 **비공개** 버킷 `macgpt-documents`를 유지합니다. 지원 MIME 목록은 기존 설정과 동일합니다. 공개 버킷으로 변경하지 마세요.
3. 운영 Vercel의 환경변수에 임의의 고강도 문자열 `CRON_SECRET`를 서버 전용으로 추가합니다. `vercel.json`은 하루에 한 번 (UTC 기준 02:00)에 `/api/internal/cleanup-attachments`를 호출합니다. Vercel의 계정/플랜별 크론 지원과 제한을 확인하세요. `CRON_SECRET`을 설정하지 않으면 크론은 403으로 실패합니다.
4. **만료는 업로드 2시간 후 즉시 파일 사용을 금지하지만**, 실제 파일 삭제는 새 대화/명시적 해제 또는 최대 100개/일 기준 크론 정리 시 이뤄집니다. 운영 규모가 커지면 시간당 정리 또는 큐 방식으로 개선하십시오. Vercel cron이 활성화되지 않은 환경에서는 수동 정리 프로세스가 필요합니다.
5. 실제 환자·직원 개인정보 또는 미검증 의료 데이터로 테스트하지 마세요. 처리 위탁/보존 정책과 악성파일 검사는 운영 공개 전 추가 검토가 필요합니다.

## 테스트

1. `npm test`, `npm run typecheck`, `npm run lint`, `npm run build` 통과 여부 확인.
2. 직원 계정 로그인 후 1MB 이하의 PDF 또는 TXT 첨부 → 문서 내용 질문 → 답변이 해당 파일을 참고하는지 확인.
3. 같은 대화에서 후속 질문 → 파일이 계속 참조되는지 확인.
4. 첨부 해제/새 대화 → 서버 저장 파일 삭제 확인.
5. 홈페이지 공개 API 키 또는 다른 직원의 파일 ID로 접근 시 HTTP 403/410으로 차단되는지 확인.
6. 만료 시간 경과 시 같은 파일이 사용되지 않는지 확인. 크론 사용 시 Storage 파일도 지워지는지 확인.
7. 첨부 기반 대화 내용이 `knowledge_items`에 자동 저장되지 않는지 확인.
8. 고객사 실제 데이터 투입 전 프롬프트 인젝션, 문서 내 명령, 대용량 PDF 비용·속도·오류, MIME 위장, 파일 악성코드 시나리오 검증 필요.

## 유의사항

- OpenAI `store:false`를 사용해 응답의 기본 저장을 끄지만, API 데이터 처리·보존 조건은 별도로 확인해야 합니다.
- PDF의 페이지 이미지까지 처리하는 경우 토큰 비용이 크게 늘 수 있습니다. 스프레드시트의 전체 데이터가 입력 컨텍스트에 실리는 것은 아닐 수 있습니다.
- 파일을 병원 정식 지식으로 등록하려면 기존 관리자 승인 흐름을 별도로 이용해야 합니다. 첨부만으로 영구 학습되는 기능은 아닙니다.
- 운영 Vercel에서 API 응답·요청 크기 제한을 피하려고 signed upload와 Storage 다운로드를 사용합니다.
