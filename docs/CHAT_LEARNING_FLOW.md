# MacGPT: 채팅 파일 학습 변경안 (2026-10-16)

## 사용법

관리자/최종관리자로 로그인 → **AI 채팅** → PDF·Word·Excel·TXT·MD·이미지를 파일 버튼 또는 **채팅 본문 전체 드래그 앤 드롭**으로 첨부 → 헤더의 **학습 모드 ON** → 예: `이 브랜드북 파일을 학습해줘. 마케팅팀 내부 지식으로 등록하고 핵심 규칙을 항목별로 나눠줘.` → 전송 → AI가 첨부 원문을 분석한 **변경안**을 확인 → **변경 승인** → 공식 지식에 반영. 학습 모드 OFF라도 명시적으로 `이 브랜드북 내용을 학습해줘`라고 하면 변경안으로 분류합니다.

일반 채팅에서는 첨부 파일을 임시 참고해 답합니다. 학습 변경안 생성은 **승인이 아니며**, 반드시 관리자가 원문과 결과를 비교해 확인한 후 승인해야 합니다. 직원은 학습/승인을 실행할 수 없습니다.

## 주의사항

- 채팅 임시 첨부는 업로드 후 최대 2시간이며 영구 원본 보관소가 아닙니다. **승인되면 변경안의 본문 내용만 공식 지식으로 저장**됩니다. 원본 브랜드북 파일도 영구 보관하려면 별도 관리자 `파일 보관함`에 등록해야 합니다.
- 문서 한 건 전체가 무손실로 변환된다고 보장하지 않습니다. 변경안은 최대 12개, 항목당 본문 12,000자이며, AI가 읽지 못한 이미지/도표/세부사항은 누락될 수 있습니다. PDF로 변환한 브랜드북을 우선 권장합니다. **중요한 수치, 컬러 코드, 로고 사용 규칙, 금지 규정 등은 반드시 원본과 비교**해야 합니다.
- 파일당 최대 10MB, 대화당 3개, 합계 20MB 제한은 동일합니다. 지식 공개 범위의 기본값은 `internal`입니다. 명시적으로 다른 범위를 지정해도 승인 과정에서 관리자가 검토해야 합니다.
- 파일과 문서의 프롬프트 지시는 실행하지 않습니다. 승인되지 않은 문서는 병원 공식 규정이 아닙니다. 개인정보/환자정보/인증정보 포함 파일은 업로드하지 마세요.
- 현재 구현은 ‘관리자 검토를 거쳐 지식 DB에 등록하는’ 학습입니다. AI 모델 가중치를 재학습시키는 파인튜닝은 아닙니다.

## 검증

1. 학습 모드 ON → 파일 드롭 → ‘학습해줘’ → 변경안 카드/승인 전 상태 확인.
2. 변경안 승인 후 `지식 관리`에서 승인 지식 확인 → 새 대화에서 해당 브랜드 원칙 질의.
3. 직원 계정으로 학습 모드/관리자 API 접근이 차단되는지 확인.
4. 다른 직원의 임시 첨부파일 ID 또는 만료된 ID로 관리자 API를 요청하면 처리되지 않아야 함.
5. 일반 파일 질문(예: ‘이 문서 요약해줘’)은 승인 변경안 없이 스트리밍 답변.
