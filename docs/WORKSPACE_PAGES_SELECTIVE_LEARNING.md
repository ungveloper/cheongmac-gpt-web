# MacGPT 페이지 라우팅 및 선택 학습

## URL
- `/chat`: AI 채팅 및 학습 검토
- `/knowledge`: 등록된 지식
- `/proposals`: 변경안 승인(승인 대기 / 승인됨 / 거절됨 탭)
- `/files`: 첨부파일 보관함
- `/members`: 회원 관리(최종관리자)
- `/api-management`: 외부 API 관리(최종관리자)

로그인 및 역할 검증은 페이지 서버 진입 시 시행한다. 최상위 `/`는 승인된 사용자에게 `/chat`으로 리디렉션한다.

## DB 마이그레이션 — 필수, 1회

`supabase/migrations/202610160001_selected_proposal_approval.sql`을 Supabase SQL Editor에서 실행한다. 기존 제안서나 승인/거절 기록은 삭제하지 않는다.

SQL 적용 전에 앱을 업데이트하더라도 기존 목록은 조회할 수 있으나 **선택 승인 요청은 실패하도록** 설계했다. SQL이 없다는 에러가 보이면 SQL 적용 후 새로고침한다.

## 항목 선택

변경안 목록과 채팅의 변경안에서 항목 오른쪽 `X`를 누르면 해당 항목은 선택에서 제외된다. `제외한 N건 되돌리기`를 누르면 원복된다. 승인 시 현재 선택된 인덱스만 API로 전송된다.

`resolve_knowledge_proposal_selected`는 서비스 역할 전용이며 서버에서 관리자의 권한을 다시 확인한다. DB 트랜잭션 안에서 제안서를 잠그고 인덱스의 범위와 유일성을 확인한 후 **선택한 항목에만** 신규 생성/수정/폐기, 버전 등록, 이벤트 기록을 실행한다. 제외한 항목의 원문은 원본 제안서에서 유지하고, 감사 기록에는 선택/제외 인덱스를 남긴다. 기존 구방식 전체 거절 RPC는 그대로 유지한다.

검토 후 `승인됨`에서는 승인된 항목만 보여주고, `거절됨`에서는 전체 거절한 제안서 원문을 보여준다. 이전 버전에서 승인한 제안서는 승인 인덱스가 NULL이고 모두 승인한 것으로 간주한다.

선택 제외는 개별 변경안의 실제 편집 기능이 아니다. 개별 문장이나 수치가 틀렸으면 X로 그 변경안을 제외하고, 수정 요청을 다시 제출해야 한다.
