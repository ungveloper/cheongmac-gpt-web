# MacGPT PDF 학습 422 오류와 드롭 영역 수정 (2026-10-16)

- 채팅 파일 드롭을 **사이드바와 상단 헤더를 제외한 오른쪽 채팅 본문**으로 제한. 사이드바에 파일을 놓아도 첨부되지 않으며 브라우저 PDF 이동을 막습니다.
- 학습 요청의 PDF 텍스트를 최대 8,000자 구간으로 나누고 요청당 변경안 최대 3건, 출력 한도 3,500 토큰으로 제한. 한 구간도 몰래 버리지 않습니다.
- OpenAI에서 HTTP 400을 반환하면 JSON 모드/토큰 상한이 없는 호환 요청으로 **최대 한 번** 다시 호출. 거절 상태가 계속되면 거절된 파라미터·API 오류 코드·요청 ID를 서버 터미널에 출력하고, 브라우저에 요청 ID를 표시합니다. 프롬프트/파일 원문/비밀키는 로그에 출력하지 않습니다.
- 변경안은 모두 **관리자 검토 및 승인 전까지 비공개**로 유지. 자동 승인이나 권한 확대 없음.
- PDF는 텍스트만 분석. 스캔 문서·로고·색상 등 시각적 요소는 텍스트로 확정하지 않습니다.
- 서버에 실시간 OpenAI 접근 권한/실제 프로젝트 키가 없으므로 400의 과거 정확한 원인은 클라이언트 스택만으로 확정할 수 없습니다. 재발한다면 `npm run dev` 터미널에 뜬 `admin assist AI failure`의 `status/code/param/request_id/detail`만 전달해 주세요. 문서 원문이나 `.env.local`은 보내지 마세요.
- 파일당 최대 10MB, 최대 3개/20MB, 승인 전 학습 내용은 기존과 같이 DB에 게시되지 않습니다.
